# English Learning System (2026-10 〜 2028-09)

2年間で「仕事・昇進・海外旅行・人生の選択肢を広げられる、実際に使える英語力」を身につけるための学習システムの設計記録。

## 現在のフェーズ

**Phase 0: 7日間診断**(2年間ロードマップは診断結果を受けて作成する)

## ファイル

| ファイル | 内容 |
|---|---|
| [01_analysis-and-strategy.md](01_analysis-and-strategy.md) | 現状と目標の分析、ボトルネック仮説、TOEIC 900 と実用英語の両立戦略、AI 英会話の使い方、ツールの暫定分類 |
| [02_7day-diagnosis.md](02_7day-diagnosis.md) | 7日間診断プログラム(日別タスク・AI プロンプト・判定ロジック) |

## 次のステップ

1. 7日間診断を実施する
2. `03_report-template.md` を埋めて報告する
3. 報告内容から以下を作成する
   - 2年間ロードマップ(0〜3 / 4〜6 / 7〜12 / 13〜18 / 19〜24か月)
   - 最初の12週間の曜日別スケジュール(通勤 / 帰宅後 / 休日)
   - 毎日の Output 設計
   - 毎月の定点観測テスト
   - TOEIC 試験ウィンドウの時期
