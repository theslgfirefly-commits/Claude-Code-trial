# 03. 診断後の報告フォーマット

7日間診断が終わったら、以下をコピーして埋め、そのまま送ってください。
**全部が揃っていなくても構いません。** 実施できなかったタスクは「未実施」と書いてください(未実施という情報自体が、負荷の設計に役立ちます)。

---

## 6-1 なぜこれらの情報が必要か

| 情報 | 使い道 |
|---|---|
| 数値(スコアシート) | ボトルネックの判定(02 の 5-5 の判定ロジック) |
| 逐語書き起こし | AI の数値を私が直接検証する。誤りのパターン、チャンクの量、構成を自分の目で確認する |
| 言えなかったリスト | 「知識不足」と「取り出し不足」の比率。最初の12週で使うフレーズ帳の種になる |
| 自己観察 | 数値では見えない、頭の中で起きていること(翻訳しているか、何を言うか決まっていないか) |
| 通勤・生活の条件 | 12週間の曜日別スケジュールを現実に合わせる |
| 360度評価の具体的な内容 | Leadership Communication の訓練を、実際の弱点に合わせる |
| 仕事の文脈 | ロールプレイのシナリオと「英語の出口」を業務に近づける |
